# Magic G.O.A.T API

NestJS API for the Magic G.O.A.T app. Setup, configuration and tests are in the [root README](../../README.md).

```bash
npm install
npm run start:dev      # http://localhost:3000, needs PostgreSQL
npx jest src           # unit tests
npm run seed           # test data (SEED_OWNER=<username> for a group and league you own)
```
